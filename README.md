# 첫소리 놀이터

교사가 TV로 진행하는 한글 첫소리(초성) 놀이 웹앱입니다.
오늘의 자음을 고르면 AI가 3단계 문제를 만들고, 그림도 바로 그려 줍니다.

- 1단계 그림 보고 첫소리 듣기 → 2단계 수수께끼 → 3단계 둘 중 고르기 → 🍫 초코 마무리
- 화면 조작: `다음` 버튼, 키보드 → / Space / Enter (다음), ← (이전)
- 정답 연출: 딩동댕 소리 + 색종이 + 칭찬 말 (상단 🔔 버튼으로 소리 끄기)
- AI 연결이 안 되면 내장된 기본 문제(14자음 × 4단어)로 자동 진행합니다.

## 배포 (Vercel)

1. 이 폴더를 GitHub에 올리고 Vercel에서 Import 합니다. (빌드 설정은 기본값 그대로)
2. Settings → Environment Variables 에 입력합니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | 필수 | OpenAI API 키 (서버에서만 사용, 화면에 노출되지 않음) |
| `APP_PASSCODE` | 권장 | 설정하면 처음 접속할 때 교사용 코드를 물어봅니다. 링크를 아는 사람이 API 비용을 쓰는 것을 막아 줍니다. |
| `OPENAI_TEXT_MODEL` | 선택 | 문제 생성 모델 (기본 `gpt-4o-mini`) |
| `OPENAI_IMAGE_MODEL` | 선택 | 그림 생성 모델 (기본 `gpt-image-1`) |

3. 환경변수를 넣은 뒤 Redeploy 합니다.

## 기본 단어 그림 미리 저장 (선택, 한 번만)

자주 쓰는 56개 단어 그림을 미리 만들어 두면, 수업 중 대기 없이 바로 나옵니다.

```
OPENAI_API_KEY=sk-... node scripts/pregenerate.mjs
```

`public/images/` 에 저장되며, 이미 있는 그림은 건너뜁니다. 저장 후 다시 배포하세요.
미리 저장하지 않아도 앱은 동작합니다. 그림은 처음 나올 때 AI가 그리고, 그 기기에 저장되어 다음부터는 바로 나옵니다.

## 구조

```
public/   화면 (index.html, style.css, app.js, seed.js, images/)
api/      question.js (문제 생성), image.js (그림 생성)
lib/      서버 공용 도우미
scripts/  pregenerate.mjs (그림 미리 만들기)
```

## 속도를 위해 한 일

- 자음을 누르는 순간 문제 요청을 미리 시작합니다. '놀이 시작'을 누를 때쯤 이미 도착해 있습니다.
- 3단계 문제를 한 번에 요청하지 않고 단계별로 나눠 동시에 요청합니다.
- 3초 안에 AI 응답이 없으면 저장된 문제로 먼저 시작하고, 늦게 도착한 문제는 아직 안 본 단계에 바꿔 넣습니다.
- 그림은 지금 화면과 다음 화면 것부터 먼저 준비하고, 새로 그리는 그림은 이 기기에 저장해 다음부터는 바로 나옵니다.
- 가장 빠른 방법은 `node scripts/pregenerate.mjs`로 기본 단어 그림을 미리 저장해 두는 것입니다.
